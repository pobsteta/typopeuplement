# Générer le jeu de données synthétique

Grille de pixels avec variables de milieu, hauteur dominante, couvert,
famille et prédicteurs simulés (métriques LiDAR, indices Sentinel-2),
vérité dendrométrique et placettes tirées dans la grille avec un bruit
de mesure. Les vraies données entrent par les mêmes colonnes. Ce jeu
n'imite aucune forêt réelle.

## Usage

``` r
generer_jeu_synthetique(ni = 60, nj = 60, n_placettes = 400, graine = 0)
```

## Arguments

- ni, nj:

  Taille de la grille, en pixels.

- n_placettes:

  Nombre de placettes tirées.

- graine:

  Graine du hasard (le générateur de l'utilisateur n'est pas touché).

## Value

Liste : `placettes`, `pixels`, `verite` (data.frame ; `verite` porte
aussi `i`, `j` et la hauteur potentielle vraie `h_pot`).

## Details

Les coordonnées des placettes sont `x = i * 25`, `y = j * 25` (m) :
pixels de 25 m.
